# 生日礼物网页交互设计

## 核心概念
一个充满爱意的个人化生日网页，融合浪漫美学和互动体验，为女朋友创造难忘的数字惊喜。

## 主要交互功能

### 1. 浪漫Heart动画开场
- 页面加载时显示漂浮的heart粒子动画
- 点击heart会显示专属的爱情讯息
- 背景有微妙的光晕效果跟随鼠标移动

### 2. 个人化生日祝福区域
- 可定制的生日蛋糕动画，点击蜡烛会有特殊效果
- 输入名字后显示个性化的祝福信息
- 动态文字效果展示爱情宣言

### 3. 回忆相册时光机
- 交互式照片轮播，展示美好回忆
- 点击照片会放大并显示当时的日期和描述
- 可以添加新的回忆照片和文字

### 4. 爱情留言板
- 实时更新的留言系统
- 可以选择不同的爱心颜色和大小
- 留言会以动画形式飘向屏幕顶部

### 5. 生日倒计时器
- 实时显示距离生日的倒计时
- 到达生日时刻时触发特殊庆祝动画
- 烟花效果和音乐播放

## 用户交互流程
1. 进入页面 → 观看heart动画开场
2. 点击heart → 查看生日祝福
3. 浏览回忆相册 → 重温美好时光
4. 留下爱情留言 → 创造新的回忆
5. 查看倒计时 → 期待生日庆祝

## 特殊效果
- 鼠标跟随的光晕效果
- 页面滚动时的视差动画
- 点击反馈的粒子效果
- 颜色渐变和发光动画
- 背景音乐播放控制
